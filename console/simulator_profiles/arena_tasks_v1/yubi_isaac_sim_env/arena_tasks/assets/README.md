# Public Toyota YUBI part meshes

These nine STL files are unmodified, independently public Toyota YUBI CAD from
revision `ce5a191c9189fbc057a808876a0daedef1519310` (v1.1.2).
They are used for the task objects, not the licensed NVIDIA Panda robot asset.

Source repository: <https://github.com/Toyota/yubi-hw/tree/ce5a191c9189fbc057a808876a0daedef1519310>.
Source file paths, direct source URLs and exact SHA-256 values are retained in
`source_manifest.json`. Source units are millimeters. Preserve the accompanying
`CERN-OHL-W-2.0.txt` license and original Toyota source notices.

The task builder converts geometry to meters and computes mass properties under
a uniform-density assumption; estimated object masses still require measurement.
The exact hardware revision seen in competition demonstrations is unverified.
